# Alpha shadow 基准与成本敏感性：2026-10-06

## 运行口径

本次使用 `.venv310` 和与上一轮相同的 11 个 PIT 窗口。输入、PIT 覆盖和
`control_prod` 重建方式不变；新增两项诊断：

- 基准：`equal_weight_xsec_available`，即每个决策日、每个 horizon 中已有
  forward return 观测的股票等权平均；缺失/未成熟观测不补零。
- 成本：`cost_bps=9.6`，按 `turnover_proxy * cost_bps / 10000` 扣减。
  9.6 bps 是 PAPER 配置中佣金、过户费、滑点和冲击成本的买入侧敏感性合计，
  不是成交回放，也未包含卖出印花税和真实成交冲击。

实验提交：`cdbf100`。原始输入、manifest、result 仍只写入本地临时目录，未写入
生产选择、PaperBook、signal freeze 或 broker 状态。

## 结果摘要

以下为 11 个窗口的均值；收益均为小数。`excess` 是相对当日可用截面等权基准，
`cost_adj` 是上述成本假设下的敏感性结果。

`control_prod` 的窗口换手代理均值为 `0.9455`，`fusion_A`/`fusion_rank_on` 为
`0.9818`。这是相邻稀疏 shadow 窗口之间的 Top-N 替换率，不是真实每日持仓换手，
所以成本结果只能用于敏感性排序，不能用于宣称可交易净收益。

## 结论与边界

1. `fusion_A` 在 1d/5d/10d/20d 的超额均值为正，但 60d/120d 为负；正 RankIC
   不能直接推出长期 Top-N 的可交易超额。
2. 成本敏感性没有改变这一结论，`fusion_A` 的长期结果仍为负，且其换手代理高于
   `control_prod`。
3. 当前不调整生产权重、不打开 `RANK_BY_FUSION`，不接入 PaperBook 或交易链路。
4. 下一步需要连续 OOS、真实持仓换手、基准一致性、Q1-Q5 单调性和更完整的成本
   回放；在这些证据完成前统一状态仍为 `not_promotable`。
