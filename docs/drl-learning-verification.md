# DRL 增量学习的验证设计（登记 + 现状差距）

> 来源：用户 2026-09-19 给出的 DRL 学习验证设计（盘后位置 / 数据流 / 三类检查点 /
> 六类风险 / 验证框架 / 降级链）。
> 本文把设计**逐项对照代码现状**，标注「已实现 / 部分 / 未实现」并给出可复核证据。
> 证据方式：全仓 grep + `data/drl/*/train_meta.json` 实际键集（16 个样本，23 个键）。
>
> **结论先说**：设计中**三类检查点里的「学习中」「学习后」全部未实现**，
> **降级链完全未实现**，且设计里两处前提需纠正（见 §〇）。

## 〇、两处前提必须纠正

1. **「硬边界约束（你已做 [0.10, 0.39]）」—— 全仓搜不到。**
   实测：`grep -E '\b0\.39\b|weight_bound|WEIGHT_BOUND|\[0\.10'` 在 `src/` 与 `scripts/`
   **零命中**。实际存在的是另一对约束：
   - `config.py` `TARGET_WEIGHT.min_mult=0.60 / max_mult=1.15`（→ 单票权重 **6.0%~11.5%**）
   - `drl_train.py` 动作裁剪 `weight_clip=0.6`
   ⇒ 请确认 [0.10, 0.39] 是指"单票权重区间"还是"因子权重区间"；若是前者，**该约束当前不存在**。

2. **DRL 并非独立调度阶段。**
   设计把 DRL 排在 19:00–21:00、独立于数据拉取与因子计算。实际：
   `daemon.py` 注释写明「**run_daily 整条管道含数据拉取+模型训练(DRL/vnpy)**」，
   且 `--maint` 在 **15:05~22:00 窗口每天跑一次**；收盘选股本身已从 15:05 **后移到 19:10**
   （因数据商收盘后 1–4h 才更新，15:45/16:40 由 `data_update_daemon` 分窗口补数）。
   ⇒ 现状是「**一条大管道**」，DRL 与选股共用边界，**没有独立的 DRL 检查点/闸门**。
   设计的时序意图（数据就绪之后、次日信号之前）大体满足，但**可观测性不满足**。

### 学习中 —— **全部未落盘，因而无从验证**

现有键全集：`algorithm, arcticdb_reward_written, attr_reward, base_weights, day,
final_weights, last_dates, llm_brief, mean_reward, model_path, n_dates, n_epochs,

## 四、六类关键风险的现状

| 风险 | 现有缓解 | 缺口 |
|---|---|---|
| 灾难性遗忘 | ❌ 无经验回放/蒸馏 | 无回放缓冲区、无蒸馏 |
| 过拟合近期 | ◐ `n_dates`/`last_dates` 限定窗口 | **无验证集划分**、未见正则化配置 |
| 奖励黑客 | ❌ | 无奖励函数审计、无行为监控 |
| 参数漂移 | ◐ `weight_clip=0.6` 动作裁剪 | 无"新旧权重差"阈值检查（数据已具备） |
| 训练不稳定 | ❌ | 无梯度裁剪、无学习率调度的**落盘证据**（无法验证是否配置） |
| **静默失败** | ◐ `train_meta.ok` + `daemon` 日志 | **无 `warn_once` 告警**；`run_daily` 失败不阻断次日；**无降级到上一版模型** |

## 五、降级链：设计 vs 现状

设计：
```
正常学习（增量训练）
  → 学习失败/验证不通过 → 保留旧模型，告警
    → 旧模型损坏 → 回退到上一个有效版本
      → 无有效版本 → 暂停交易，人工介入
```

现状（实测）：**四级降级一级都没有独立实现**。
- 「学习失败」：`train_meta.ok=False` 会落盘，但**没有 `warn_once` 告警**、也没有阻断；
- 「保留旧模型」：因为模型按天分目录，旧文件**物理上还在**，但**消费方不会自动回退**；
- 「回退到上一个有效版本」：未见任何"扫描 `data/drl/*` 找最近一个 `ok=True` 的模型"逻辑；
- 「无有效版本 → 暂停交易」：**未见**该闸门。

⇒ 这与 f_ml 的降级链（已修）形成对比：**DRL 侧仍是裸奔**。

**可低成本先做的一条**：`DRL-4` 与"参数漂移检查"——因为 `base_weights`/`prior_weights`/
`final_weights` 已经落盘，加一条 `|final - prior| <= 阈值` 的断言 + 告警即可，
**无需改训练逻辑**。建议作为 DRL 侧的第一个改动。
