# DuckDB 兼容边界

记录日期：2026-10-02  
适用分支：`cleanup/phase0-baseline`

## 结论

DuckDB 目前仍处于兼容层和运维链中，不能按“全仓删除”处理。后续清理原则是：

1. 保留已有兼容读取/写入路径，直到 h5i 等价链路和外部入口完成验证；
2. 不再新增业务模块对 DuckDB 的直接调用；
3. 只删除已经通过调用图和回归测试确认无调用方的分支；
4. 新代码优先通过明确的适配器或配置入口访问数据，不复制路径常量。

## 当前使用点

| 文件 | 主要角色 | 读/写性质 | 处置 |
| --- | --- | --- | --- |
| `src/agent_tools.py` | 研究/运维工具兼容查询 | 读，含回退 | 保留，后续确认调用频率 |
| `src/backfill_change_pct.py` | 历史字段补录 | 写/补录 | 保留为一次性维护入口，不能与生产读取混删 |
| `src/build_factor_views.py` | 旧视图/物化链兼容 | 读写或物化 | 保留，先验证 h5i 等价结果 |
| `src/backtest_engine.py` | 回测数据源兼容 | 读，含 `BAR_STORE=duck` 分支 | 保留 legacy 适配路径 |
| `src/dashboard.py` | 面板查询与手动更新 | 读，可能触发更新 | 保留，需与 `update_db` 的职责对齐 |
| `src/cn_lake_feed.py` | 数据源连接封装 | 读 | 保留，确认外部脚本调用后再收敛 |
| `src/update_db.py` | 数据更新链 | 写/更新 | 保留，属于运维入口 |
| `src/tasks_db.py` | 异步更新任务封装 | 间接读写 | 保留，和 Celery 生命周期一起管理 |
| `src/config.py` | 路径、目标和历史兼容配置 | 配置定义 | 不因注释中的“退役”字样直接删除 |

上述列表来自 Phase 2 调用图；命中数包含注释、测试和文档，不能单独作为生产调用证明。

## 迁移判据

只有同时满足以下条件，才可以删除某个 DuckDB 分支：

- 生产入口已切换到 h5i 或其他明确的数据适配器；
- 旧路径和 fallback 的测试已迁移，且完整回归通过；
- `ops/`、计划任务、外部脚本和 dashboard 按钮不再依赖该入口；
- 迁移前后的同日同标的一致性已有可复现证据；
- 文档、配置模板和回滚方式已同步更新。

## 不做的动作

本阶段不删除 `DUCKDB_PATH`、`BAR_STORE=duck` 或其他兼容常量，也不把 DuckDB 与 h5i 的路径常量强行合并。若未来确认某个常量无调用，应单独提交、单独测试并保留回滚点。
